# CareAble 🫶

Supporting hidden caregiving workers through self-assessment and skill recognition.

## 📖 About

CareAble is a web platform that allows unpaid caregivers to:
- Self-assess their caregiving skills
- Align their capabilities with the Australian Skills Classification
- Receive a digital certificate upon completion
- Visualize their skills through a capability heatmap

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js + Express
- **Database:** MongoDB Atlas
- **Authentication:** JWT

## 📁 Project Structure

- `/client` — React frontend (mobile-first)
- `/server` — Node.js + Express backend API
